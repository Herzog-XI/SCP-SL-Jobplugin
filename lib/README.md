# Required SCP:SL assemblies

Copy the following files from your SCP: Secret Laboratory server installation into this folder:

- `SCPSL_Data/Managed/UnityEngine.CoreModule.dll`
- `SCPSL_Data/Managed/Assembly-CSharp-firstpass.dll`

Possible additional references for future features:

- `SCPSL_Data/Managed/UnityEngine.PhysicsModule.dll`
- `SCPSL_Data/Managed/Mirror.dll`

Do not copy the complete `Managed` directory. Only add assemblies that are explicitly referenced by the project.
